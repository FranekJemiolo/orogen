Orogen Protocol v1.0.0

Decentralized, browser-based quant data lakehouse.

Core Components

  • DuckDB-Wasm Engine: In-browser vector OLAP execution supporting ASOF joins across diverse temporal feeds.
  • OPFS Storage & LRU Eviction: High throughput chunk storage with quota enforcement and non-blocking read streams.
  • Sandboxed Pyodide ETL: Deterministic Python data transformations with strict URL allowlists and sandbox containment.
  • Nostr-Signaled WebRTC P2P Mesh: Ephemeral Kind 29333 peer rendezvous with 64KB SCTP backpressure control.
  • Cryptographic Strike System: SHA-256 chunk Merkle verification with peer banning and automatic failover.
  • Iceberg Catalog Service Worker: Intercepts REST calls to https://orogen.local/api/v1/ to fool DuckDB into streaming local OPFS data.
